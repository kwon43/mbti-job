# 🧭 나에게 어울리는 진로는?

고등학생을 위한 **MBTI 기반 진로탐색 웹앱**입니다. 🌱

MBTI 유형을 선택하면 해당 유형에서 나타날 수 있는 성향과 강점을 살펴보고, 이를 바탕으로 탐색해 볼 만한 **직업 3가지**를 추천합니다.

> 💡 MBTI만으로 진로를 결정하기 위한 것이 아니라, 자신의 관심과 강점을 탐색하는 참고용 프로그램입니다.

## ✨ 주요 기능

- 🧩 16가지 MBTI 선택
- 🌱 유형별 성향과 강점 확인
- 💼 유형별 직업 3가지 추천
- ❤️ 관심 직업 저장
- 🔎 진로 탐색 질문
- 📱 모바일에서도 보기 좋은 반응형 UI
- 🎈 이모지와 카드형 디자인
- 📄 `pages` 폴더 없이 `app.py` 하나로 구성

## 🛠️ 사용 기술

- Python
- Streamlit
- HTML/CSS

## ⚠️ 중요한 안내

MBTI는 사람의 성격과 선호를 이해하는 여러 방법 중 하나입니다.

특정 MBTI라고 해서 특정 직업에 반드시 적합하거나 부적합한 것은 아닙니다.

진로를 결정할 때는 다음 요소를 함께 고려하는 것이 좋습니다.

- ❤️ 내가 좋아하는 것
- 💪 내가 잘하는 것
- 🧠 나의 관심 분야
- 🎯 중요하게 생각하는 가치
- 📚 학습 경험
- 🏫 학교생활과 동아리 활동
- 🌎 다양한 진로 경험

**나에게 맞는 진로에는 정답이 하나만 있는 것이 아닙니다.** 🌈

## 🌟 제작 목적

고등학생이 자신의 성향을 가볍게 살펴보고 다양한 직업을 탐색하면서 자신의 진로에 대해 생각해 볼 수 있도록 제작한 프로그램입니다.

**"MBTI가 내 진로를 정해주는 것"이 아니라 "MBTI를 계기로 내 진로를 더 생각해 보는 것"**을 목표로 합니다. 🌱
